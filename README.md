# Partage Vacances 💰

Application web pour répartir facilement les dépenses entre plusieurs familles/groupes lors de vacances communes (gestion par parts, calcul automatique des remboursements optimaux).

## Fonctionnalités

- Créer des familles/groupes et y ajouter des membres (avec un nombre de parts chacun)
- Enregistrer une dépense : montant, payeur, familles et personnes présentes
- Récapitulatif des soldes de chacun et liste optimisée des remboursements à effectuer
- Sauvegarde automatique dans le `localStorage` du navigateur

## Stack

- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [lucide-react](https://lucide.dev/) pour les icônes

## Démarrage

```bash
npm install
npm run dev
```

## Build de production

```bash
npm run build
npm run preview
```
